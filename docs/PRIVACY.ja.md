# ClipySi プライバシーポリシー

[English](PRIVACY.md) · **日本語**

_最終更新: 2026-06-27_

ClipySi は macOS 向けのクリップボードマネージャです。クリップボードマネージャは
パスワードやトークンを含め、コピーしたものをすべて扱うため、プライバシーを後付けでは
なく**最優先の設計前提**としています。

## 概要

- **すべてあなたの Mac 内に留まります。** クリップボード履歴とスニペットはローカルに
  保存され、ClipySi がアップロードすることはありません。
- **既定ではテレメトリを送りません。** 診断は初期状態で**オフ**の opt-in です。
  有効にしてもローカルで収集されるだけで、自動送信は一切ありません。
- **クリップボードの内容は診断に収集しません** — 本文も、タイトルも、スニペット本文も、
  検索語も含みません。
- **広告・analytics SDK・第三者トラッカーは一切ありません。**

## ClipySi が扱うデータ

| データ | 保存場所 | 備考 |
| --- | --- | --- |
| クリップボード履歴（コピーしたテキスト・画像・ファイル） | あなたの Mac 内のみ | 保存時に暗号化（下記）。 |
| 作成したスニペット | あなたの Mac 内のみ | ローカル DB に保存。 |
| 設定 | あなたの Mac 内のみ（`UserDefaults`） | 履歴件数・ホットキー・診断レベルなど。 |

ClipySi にはアカウント・ログイン・サーバーがありません。データを受け取る
バックエンドは存在しません。

## ローカル保存と暗号化

- コピー内容（クリップ本体・サムネイル）は CryptoKit の **AES-GCM** で保存時に
  暗号化され、ディスクには暗号文として書き込まれます。データベースには**メタデータ
  のみ**が入り、コピー内容の平文は含みません。
- 暗号鍵は macOS の **Keychain** に
  `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly` で保存され、端末に束縛されて
  iCloud に同期しません。
- pasteboard のプライバシーマーカー（`org.nspasteboard.ConcealedType` /
  `TransientType` / `AutoGeneratedType` とレガシー同義タイプ）は、**内容を読む前に**
  尊重します。パスワード欄などの concealed なコピーは保存されません。
- 検出された機密情報（パスワード・API キー・トークン）はメニューと履歴一覧で
  **端末内でマスク**されます。検出は完全にあなたの Mac 内で行われ、どこにも送信されません。

## ClipySi が決して収集・送信しないもの

- クリップボードの内容、画像、ファイルパスの完全値。
- クリップのタイトル、スニペット本文、検索クエリ。
- メールアドレス、OAuth トークン、暗号化鍵、パスフレーズ。
- コピー元アプリの名前や bundle id。

## 診断（opt-in・既定オフ）

クラッシュや不具合の修正のため、ClipySi は少量の**匿名・端末内**の診断情報を収集
できます。これは**既定でオフ**です。初回起動時にレベルを選べ、いつでも
**設定 → 診断**で変更できます。

診断は**あなたの Mac 内だけ**で収集されます。ClipySi が自動的にどこかへ送信する
ことは**ありません**。開発者に共有したい場合は**「診断をエクスポート…」**で
バグ報告に添付できるフォルダを書き出せます。書き出される内容は設計上、本文を
含みません（下記）。

| レベル | 収集する内容 |
| --- | --- |
| **オフ**（既定） | 何も収集しません（インストール識別子すら作りません）。 |
| **最小** | クラッシュレポート（Apple の MetricKit 経由）、アプリと macOS のバージョン、CPU アーキテクチャ、匿名の端末内インストール ID。 |
| **標準** | 最小に加えて、エラー時の大まかな機能領域（例 `paste`・`menu`）と同期の種類。 |
| **詳細** | 標準に加えて、直近の大まかな足跡（機能名のみ）。 |

収集項目は設計上限定されています。診断イベントはあらかじめ定義された分類（機能
領域・エラー種別）しか持てず、自由なテキストを運べません。クリップボードの内容を
診断に付与できるコード経路は存在せず、これは変更のたびにプロジェクトの自動テストで
強制されます。

**匿名インストール ID。** 最小以上を選ぶと、ClipySi は繰り返しの報告を関連付ける
ために、あなたの Mac 内でランダムな識別子を生成します。これはあなた・Apple
アカウント・その他の身元には結び付かず、診断がオフの間は決して作成されません。

**Apple のクラッシュレポート。** macOS 自体は、**OS レベルで opt-in している場合に
限り**（システム設定 → プライバシーとセキュリティ → 解析と改善 → *App デベロッパと
共有*）、Apple のツール（Xcode Organizer）を通じて開発者へクラッシュレポートを
届けることがあります。これらは Apple が生成・redaction するもので、クリップボードの
内容は含みません。これは [Apple のプライバシーポリシー](https://www.apple.com/legal/privacy/)
に従う Apple の機能であり、ClipySi は制御しません。

## ソフトウェアアップデート

自動アップデート確認が有効な場合、ClipySi は [Sparkle](https://sparkle-project.org)
を使ってアップデートフィード（appcast）をネットワーク越しに取得します。この要求は
あらゆる web 要求と同様、フィードを提供するサーバーに IP アドレスと基本的な
user-agent を必然的に伝えますが、クリップボードデータや診断は一切含みません。
自動確認は**既定でオン**です。About ウィンドウでいつでもオフにしたり、手動で
アップデートを確認したりできます。

## 第三者サービス

ClipySi には広告 SDK・analytics SDK・第三者クラッシュレポーターは**一切ありません**。
唯一のネットワーク通信は上記のアップデート確認のみです。

## データの保持と削除

- クリップボード履歴は、削除する（項目単位または「履歴を消去」）か、設定した最大
  件数を超えて最古の項目が削られるまで、ローカルに保持されます。スニペットは削除
  するまで残ります。
- 保存されたクラッシュレポートと診断は、削除するまであなたの Mac に残ります。
- ClipySi を**アンインストール**し、データディレクトリと Keychain 項目を削除すれば、
  ClipySi が保存したものはすべて消えます。サーバーが存在しないため、遠隔で削除を
  依頼する対象はありません。

## 子どもについて

ClipySi は汎用の開発者・生産性ツールであり、子どもを対象としていません。

## 本ポリシーの変更

本ポリシーが変更された場合、更新版を新しい「最終更新」日とともに ClipySi の
リポジトリで公開します。
