# ClipySi for macOS

[English](README.md) · **日本語**

**ClipySi は、プライバシー重視のクリップボードマネージャです。**

ClipySi は、コピーした内容を検索可能な履歴として保存し、過去の項目やスニペットをすばやく貼り付けられるアプリです。
macOS 版は [Clipy](https://github.com/Clipy/Clipy) の使い心地を参考にした独立リライトとして開発しています。
Clipy プロジェクトとは無関係であり、公認されたものではありません。
`Clipy` / `ClipMenu` という製品名を再利用しないよう、アプリ名を **ClipySi** に変更しています。

## ダウンロード

[ClipySi 1.0.0 は GitHub Releases からダウンロードできます。](https://github.com/ClipySi/clipy-si-macos/releases/latest)

配布ビルドは Developer ID で署名し、公証済みです。
Apple Silicon と Intel の両方に対応したユニバーサルビルドで、macOS 14 Sonoma 以降で動作します。
Sparkle 2 による自動アップデートにも対応しています。

## 主な機能

### クリップボード履歴

- pasteboard を監視し、コピーした内容を検索可能な履歴として保存します。
- テキストだけでなく、RTF、RTFD、PDF、ファイル名、URL、TIFF などの表現形式を扱えます。
- 再コピーされた項目を先頭に戻す重複検出に対応しています。
- 履歴数の上限、古い履歴の自動削除、ディスク上の blob ガベージコレクションに対応しています。
- 指定したアプリからのコピーを保存しない除外アプリ設定があります。
- デスクトップに保存されたスクリーンショットの自動取り込みをオプトインで有効にできます。

### メニューと貼り付け

- メニューバーのステータスアイテムから履歴、スニペット、設定へアクセスできます。
- グローバルホットキーで、カーソル位置に履歴パネルを開けます。
- 先頭の履歴項目には `⌘0`–`⌘9` の数字キーショートカットを割り当てます。
- 最前面アプリへの貼り付けは `CGEvent` による `⌘V` 注入で行います。
- 貼り付けた項目を既定で履歴の先頭に移動します（設定でオフにできます）。
- プレーンテキスト貼り付け、履歴から削除、貼り付け後に削除する修飾キー操作に対応しています。

### スニペット

- フォルダとスニペットを管理し、メニューから素早く貼り付けられます。
- SwiftUI の 3 ペインエディタで、作成、編集、削除、並べ替え、フォルダ移動ができます。
- オリジナル Clipy のスニペット XML 形式と互換のインポート／エクスポートに対応しています。

### システム連携

- `SMAppService` によるログイン時起動に対応しています。
- Sparkle 2 の EdDSA 署名付き appcast による更新確認に対応しています。
- 設定画面では、一般設定、メニュー、保存タイプ、除外アプリ、ショートカット、プライバシーを管理できます。

## セキュリティとプライバシー

クリップボードマネージャは、パスワードやトークンを含め、ユーザーがコピーする内容を扱います。
ClipySi はこの性質を前提に、保存前、保存時、表示時のそれぞれで保護を入れています。

- pasteboard の `TransientType` / `ConcealedType` / `AutoGeneratedType` などのプライバシーマーカーを、内容を読む前に確認します。
- プライバシーマーカー付きのクリップは保存しません。
- 履歴ペイロードとサムネイルは AES-GCM で暗号化して保存します。
- 暗号鍵は Keychain に保存し、`ThisDeviceOnly` 属性でこのデバイスに紐付けます。
- 重複検出には Keychain の鍵で鍵付けした HMAC-SHA256 を使います。
- パスワード、API キー、トークンなどは、表示時にオンデバイスで検出して伏字化します。
- 機密マスキングは表示専用なので、実際に貼り付ける内容は変わりません。
- マスクされた項目の貼り付け前に、任意で Touch ID またはパスワード確認を挟めます。
- 診断は opt-in で、既定ではオフです。
- クリップボード内容の自動送信はありません。
- 貼り付けには macOS の Accessibility 権限が必要です。
- Input Monitoring は要求しません。

共有 Rust コア `clipy-si-core` は別リポジトリで管理され、この公開リポジトリには実装を含みません。
リリースアプリにはビルド済みのバイナリ（静的リンク）として組み込まれます。
機密マスキング、暗号、record/vault 形式、同期判定はそのコアで実装されています。

詳しくは[プライバシーポリシー](docs/PRIVACY.ja.md)、[配布マトリクス](docs/DISTRIBUTION.md)、[セキュリティポリシー](SECURITY.md)を参照してください。
実装上のセキュリティ要件は [security-guidance.md](security-guidance.md) にまとめています。

## 動作要件

- macOS 14 Sonoma 以降
- Apple Silicon または Intel Mac
- ソースからビルドする場合は Xcode 26.5 と macOS 26 SDK

## ソースからのビルド

通常の利用には、署名・公証済みのリリースビルドを使ってください。

アプリは共有 Rust コア（`ClipySiCore`）を、リリースに同梱されるビルド済みのバイナリ（静的リンク）
として利用します。Xcode が Swift パッケージ依存として解決するため、アプリのビルドにコアのソースは
必要ありません。コアは別リポジトリで開発されており、コア自体を変更する場合のみ必要になります。

リポジトリを clone します。

```bash
git clone https://github.com/ClipySi/clipy-si-macos.git
cd clipy-si-macos
```

full Xcode が選択されていることを確認します。

```bash
xcode-select -p
# /Applications/Xcode.app/Contents/Developer 以外を指している場合:
# sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

Debug ビルド:

```bash
set -o pipefail && xcodebuild \
  -project Clipy.xcodeproj \
  -scheme Clipy \
  -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -skipMacroValidation \
  CODE_SIGNING_ALLOWED=NO \
  build 2>&1 | xcbeautify
```

テスト:

```bash
set -o pipefail && xcodebuild \
  -project Clipy.xcodeproj \
  -scheme Clipy \
  -destination 'platform=macOS,arch=arm64' \
  -skipMacroValidation \
  -testLanguage en -testRegion US \
  CODE_SIGN_IDENTITY=- CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=NO \
  test 2>&1 | xcbeautify
```

Lint:

```bash
swiftlint lint --quiet
swiftlint --fix
```

`-skipMacroValidation` はすべての `xcodebuild` CLI 実行で必要です。
テストは `-testLanguage en -testRegion US` で英語に固定してください。
ローカルの ad-hoc 署名ビルドでは、リビルドのたびに macOS が Accessibility 権限を再要求することがあります。

## アーキテクチャ

ClipySi は SwiftUI App ライフサイクルを使いながら、メニューバー、グローバルホットキー、pasteboard 監視、貼り付け注入などの macOS 固有処理を AppKit 側で管理します。

`@NSApplicationDelegateAdaptor` 配下の `AppDelegate` が `NSStatusItem`、非アクティブ化 `NSPanel`、pasteboard ポーリング、`CGEvent` 貼り付け、ログイン項目、Sparkle updater を所有します。
履歴やスニペットの表示は、カーソル位置に開く統合フローティングパネルに集約しています。

永続化には SQLiteData / GRDB を使います。
データベースにはメタデータを保存し、クリップの本体やサムネイルは暗号化 blob としてディスクに保存します。
write は repository 経由に集約し、SwiftUI からは `@FetchAll` のライブクエリで参照します。

並行性は Swift 6 strict concurrency を前提にしています。
AppKit、メニュー、貼り付け、ホットキー周辺は `@MainActor` に寄せ、ドメインをまたぐ値型は `Sendable` として扱います。

設計の詳細は [DESIGN.md](DESIGN.md) を参照してください。

## 技術スタック

| 関心事 | 選択 |
| --- | --- |
| UI | SwiftUI + AppKit |
| 永続化 | SQLiteData / GRDB / swift-structured-queries |
| 依存注入 | swift-dependencies / swift-sharing |
| ホットキー | Magnet / Sauce / KeyHolder |
| スクリーンショット監視 | Screeen |
| スニペット XML | AEXML |
| 暗号 | CryptoKit / Keychain / Rust コア |
| ログイン項目 | SMAppService |
| 自動アップデート | Sparkle 2 |

オリジナル Clipy で使われていた Realm、RxSwift、PINCache、XIB、`NSCoding`、LoginServiceKit は使っていません。

## コントリビュート

Issue と pull request を歓迎します。

アプリはビルド済みの ClipySiCore バイナリをリンクするため、ビルドにコアのソースは必要ありません。
公開 CI では SwiftLint と redaction/logging ゲートを実行し、macOS の full build/test はメンテナ環境で実行します。

PR を出す前に、可能であれば `swiftlint lint --quiet` とテストスイートを実行してください。
セキュリティに関わる変更は、[security-guidance.md](security-guidance.md) と照合してください。
脆弱性を見つけた場合は、public issue ではなく [SECURITY.md](SECURITY.md) の手順で非公開に報告してください。
